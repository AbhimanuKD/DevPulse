DevPulse OS V-1: a real operating system in 9 KB

Written from scratch in C and assembly. It boots on a PC with BIOS and runs in 128 MB of RAM. These screenshots are from the real OS, tested in a virtual PC.

Boot screen: RAM check passes the 128 MB target.

Download V-1 Download ISO 1.8 MB, for VirtualBox, VMware, QEMU Download disk image 1 MB, raw .img View source code on GitHub
  • CPU32-bit x86
  • BootLegacy BIOS (not UEFI)
  • RAM128 MB
  • Kernel sizeabout 9 KB
  • LanguagesC and assembly
qemu-system-i386 -m 128 -cdrom devpulse-os-v1.iso -boot d

This terminal is a browser simulation of the V-1 shell so you can try the commands. The real OS is the ISO above. V-1 cannot run Windows or Linux programs, and files are lost on reboot. It is a learning project, not a replacement for Windows.
