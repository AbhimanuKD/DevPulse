## What is inside

| Section | What it does |
|---|---|
| **Hero** | Headline, calls to action and a live "AI Agent Pulse" dashboard with a heartbeat line |
| **AI agent workspace** | A prompt builder (web scraper, code optimizer, automation bot) with a copy button, plus a streaming API console log |
| **Projects** | Insight Agent, Workflow Orchestrator, Pulse Monitoring and six work areas, with filters for AI, Tools and Systems |
| **DevPulse OS concept** | A clickable desktop prototype with Browser, Terminal, Files and Agents apps |
| **Profile** | About, focus areas and links |

> **Note:** DevPulse OS is a concept and interface prototype only. A real operating system needs kernel engineering, signed drivers and hardware testing.

## Tech

- Plain **HTML, CSS and JavaScript**. No build step, no dependencies.
- One page: `index.html`
- Fonts: Bricolage Grotesque and IBM Plex (Google Fonts, with system fallbacks)
- Works on phones, tablets and desktops
- Keyboard friendly, visible focus, and respects "reduce motion"

## Run it on your computer

1. Download or clone the repo
   ```bash
   git clone https://github.com/AbhimanuKD/DevPulse.git
   ```
2. Open `index.html` in your browser. That is all.

## Publish on GitHub Pages

1. Push these files to the `main` branch
2. Go to **Settings → Pages**
3. Under **Source**, choose **Deploy from a branch**, then `main` and `/ (root)`
4. Wait about a minute. Your site is at `https://abhimanukd.github.io/DevPulse/`

## Make it yours

- **Stats** (`8+ stacks`, `30+ workflows`): search for `class="stats"` in `index.html` and put your real numbers.
- **Projects**: search for `class="item"` and edit the title, text and tags.
- **Colors**: change the values at the top of the `<style>` block under `:root`.
- **Prompts**: edit the `P` object in the `<script>` block.
